## 📌 未排入但想去的口袋景點介紹

### 1. 五色沼（裏磐梯）
* **景點介紹**：位於福島縣裏磐梯的五色沼，是由數十個因火山運動形成的湖沼群總稱。由於水中含有不同的礦物質與植物，加上陽光折射，每個湖沼會呈現出翠綠、鈷藍、寶石藍等幻化莫測的色彩。
* **冬季特色**：冬天的五色沼被厚雪覆蓋，枯樹與冰藍色的湖水形成強烈的對水墨畫美感。雖然本次為了安全考量取消了較具挑戰性的雪鞋健行，但若未來有機會造訪，其周邊平緩的步道在積雪期依然能欣賞到極具神祕感的雪國秘境風光。

### 2. 山寺（寶珠山立石寺）
* **景點介紹**：位於山形縣的「山寺」是日本東北最具代表性的靈場之一，由慈覺大師於西元 860 年創建。整座山頭都是寺廟範圍，以沿著斷崖絕壁而建的「根本中堂」和「開山堂」、「五大堂」聞名。
* **冬季特色**：參拜山寺需要挑戰約 1,015 級的石階步道。冬天下雪時，兩旁巨大的杉木林覆滿白雪，登頂至「五大堂」俯瞰被大雪染白的山形市郊與村落景致，猶如置身於仙境水墨畫中，是攝影愛好者與景致控極度嚮往的冬日絕景。
